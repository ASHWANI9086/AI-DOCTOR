# 🩺 VisionaryCare — AI Doctor That Sees & Speaks

An AI-powered medical assistant that analyzes medical images (skin, X-ray, eye, dental, etc.) and provides voice diagnosis using Groq LLaMA-4 Vision + gTTS.

## Features
- 🖼️ Medical image analysis (skin, X-ray, dental, eye conditions)
- 🎤 Voice input — record or upload your symptoms
- ✍️ Text input — type your symptoms
- 🔊 Voice output — doctor speaks the diagnosis
- 🧠 Powered by Groq LLaMA-4 Scout Vision model

## Tech Stack
- **AI Model**: Groq LLaMA-4 Scout 17B (Vision)
- **Speech-to-Text**: Groq Whisper Large V3
- **Text-to-Speech**: gTTS
- **UI**: Gradio
- **Container**: Docker
